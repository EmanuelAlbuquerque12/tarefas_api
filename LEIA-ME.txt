┌────────────────────────────────────────────────────────────────┐
│  PARA COMEÇAR (Duplo-clique nos arquivos):                    │
└────────────────────────────────────────────────────────────────┘

   🟢 iniciar.bat
      → Inicia TUDO automaticamente (RECOMENDADO)
      → Instala dependências
      → Abre navegador
      → Pronto para usar!


┌────────────────────────────────────────────────────────────────┐
│  OUTROS COMANDOS ÚTEIS:                                        │
└────────────────────────────────────────────────────────────────┘

   🔴 parar.bat
      → Para o servidor

   🧪 testar.bat
      → Testa conexão com API ProJuris
      → Use para diagnosticar problemas

   ⚙️  configurar.bat
      → Menu interativo de configuração
      → Editar credenciais
      → Reinstalar dependências
      → Limpar cache

   🌐 abrir-dashboard.bat
      → Abre o navegador (servidor já deve estar rodando)


┌────────────────────────────────────────────────────────────────┐
│  PRIMEIRO USO:                                                 │
└────────────────────────────────────────────────────────────────┘

   1. Duplo-clique em "iniciar.bat"
   2. Se solicitado, configure o arquivo .env com suas credenciais
   3. Dashboard abre automaticamente!


┌────────────────────────────────────────────────────────────────┐
│  PRÉ-REQUISITO:                                                │
└────────────────────────────────────────────────────────────────┘

   ⚠️  Node.js precisa estar instalado
   📥 Download: https://nodejs.org/ (versão LTS)


┌────────────────────────────────────────────────────────────────┐
│  CREDENCIAIS PROJURIS:                                         │
└────────────────────────────────────────────────────────────────┘

   Você precisará configurar no arquivo .env:

   • PROJURIS_DOMAIN
   • PROJURIS_USER
   • PROJURIS_PASSWORD
   • PROJURIS_CLIENT_ID
   • PROJURIS_CLIENT_SECRET

   💡 Use "configurar.bat" para editar facilmente!


┌────────────────────────────────────────────────────────────────┐
│  PROBLEMAS?                                                    │
└────────────────────────────────────────────────────────────────┘

   1. Execute "testar.bat" para diagnosticar
   2. Verifique o arquivo README.md para mais detalhes
   3. Veja INICIO_RAPIDO.md para solução de problemas


┌────────────────────────────────────────────────────────────────┐
│  USO DIÁRIO:                                                   │
└────────────────────────────────────────────────────────────────┘

   Manhã:    Duplo-clique em "iniciar.bat"
   Trabalho: Use o dashboard normalmente
   Noite:    Duplo-clique em "parar.bat"
